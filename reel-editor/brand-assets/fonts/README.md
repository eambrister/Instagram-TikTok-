Put licensed **Heading Now** (headings) and **Gotham** (body/captions) .ttf/.otf files here, then run `npm run setup`.
Family names are read from the font files themselves. Until then, open-license fallbacks are used and reported in every QA report:
Barlow Condensed ExtraBold (headings, from ../brand/fonts) and Inter Black/Bold (captions/body, from @fontsource/inter).
Font files are git-ignored so licensed fonts are never published to the repository.
