# Monumental kit (second brand kit)

This is a second visual style for Edison Ambrister: cinematic, photo-led and editorial, with Bodoni-style serif headlines, bone and antique-gold type, and optional sculpture or architecture as metaphor. It sits **alongside** the core kit in [`../CONTENT_SYSTEM.md`](../CONTENT_SYSTEM.md) and does not replace it.

| File | Purpose |
|---|---|
| [`STYLE_GUIDE.md`](STYLE_GUIDE.md) | Full rules: when to use the kit, canvas, palette, type, layouts A–H, identity protection, narrative, workflow, input card, quality gate |
| [`CAPTION_SYSTEM.md`](CAPTION_SYSTEM.md) | Caption rules: hook → body → close → CTA → 5 hashtags + up to 30 search tags |
| [`tokens.json`](tokens.json) | Machine-readable values for generators |
| [`kit-preview.png`](kit-preview.png) | Palette and type specimen (no person; a placeholder backdrop) |
| [`source-guides/`](source-guides/) | The four original PDFs the kit was built from |

The source guides document another creator's campaign. Their people, slogans, marks and offers are references only and must never appear in Edison's work.
