# Craving swaps

A six-slide Instagram carousel (EDISON EATS), 1080 × 1350. It uses the format of a "craving X means you need Y" post Edison saved. The deficiency claim in that format isn't supported by evidence, so this version is reframed as practical swaps.

- Upload `jpg/01-hook.jpg` to `jpg/06-close.jpg` in order (or `final-carousel.zip`).
- Caption: `caption.txt`

**AI imagery:** the food rows were generated with ElevenLabs (gpt-image-2.5-sunburst). The sources are in `source-images/`. Tick Instagram's AI label when posting.

Rebuild: `python3 tools/build_monumental_craving_swaps.py`
