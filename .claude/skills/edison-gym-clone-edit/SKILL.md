# Edison Gym Clone Edit

Read `../_shared/edison-video-standard.md` first. Default 9:16, 30 fps, about 35–40 s.

## Coverage this style needs
Locked-off views (incline work, seated press, cable or pull-up, high-angle ensemble), detail inserts of a dumbbell and a rope, front/side/back angles of one overhead press, and a hand covering the lens. Map every planned effect to an actual clip; where coverage is missing, say which effect is unsupported and deliver the strongest version possible — never fake coverage.

## Arc
Unusual opening pose + a small question line → empty bench with staccato Edison appearances → incline action → dumbbell portal → seated press flanked by two independent standing clones → pop-out → rope silhouette and grip match → cable exercise with a background clone → pull-up → walking echoes → angle bursts → multi-clone finale → collapse to one → hand wipe to black → CTD end card.

## Rules
- Clones are separate performances, opaque, rotoscoped with their equipment, with correct floor contact, shadows and occlusion behind machine parts. A duplicated rectangle is not a clone; mirrors are not clones. Time-offset copies only for the walking trail.
- Portal: keep the outgoing equipment's rim over the incoming scene and scale until it leaves frame — not a zoom blur.
- Silhouette reveal: exactly three frames, shaped from the object's real alpha.
- Angle bursts: three-frame segments matched on bar height, elbow position and direction — an accent, not a reason to cut everything fast.
- Grade: cyan/green surroundings mapped into Edison's graphite, warm skin, deep blacks. Composite first, then one shared grade.
- Timings are starting points; adapt to the new action and track. Inspect every compositing frame, then watch at speed and listen before final export.
