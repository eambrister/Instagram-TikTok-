# Edison video-editing skills

Twenty Claude Code skills that apply cinematic editing techniques to **Edison Ambrister's** saved style. Claude Code loads them automatically in this repo. Ask for one by name, for example: *"Use edison-gym-reel-cover for this clip."*

Every skill starts from [`_shared/edison-video-standard.md`](_shared/edison-video-standard.md). It covers identity (Edison Ambrister name, Cut Throat Discipline logo, the DISCIPLINE - ACCOUNTABILITY - CONSISTENCY footer), the palette and font mapping, formats, copy rules, honesty and verification, and which steps run on Edison's computer versus this cloud repo. To pick a skill, use [`edison-production-standard`](edison-production-standard/SKILL.md).

## Provenance

These are original write-ups in Edison's brand, based on a private editing collection he received for personal use. That collection's text, scripts, LUTs, reference images, PDFs and the original creator's marks are deliberately **not** stored in this public repository. Edison keeps the originals in his Google Drive. Before using any original script on his own machine, read it first.
