# Edison Cinematic Gym

Read `../_shared/edison-video-standard.md` first. Deliver three things, in order: the film, the cover, the caption. If only one is asked for, make only that one.

## Film
1. **Direct.** Inspect real source intervals. Fix subject (Edison only — no background athletes or mirror reflections unless the brief allows), camera profile, music, a specific opening action and a payoff. Choose routine creative details yourself.
2. **Cut in Resolve.** Frame-addressed sequence on a new named timeline; keep earlier timelines. Readable reps: held effort passages with short detail bursts, not uniform machine-gun cuts. Default 1080×1920, source cadence, as long as the footage and track justify.
3. **Effects around real poses.** Mix a few of: incoming-body handoff (masked Edison arrives before his scene, continuous source time), opaque clones placed with real floor contact, graphic ivory/crimson portrait flash, slam shake on impacts, slow-motion drag that protects the body. Never the same effect on every cut.
4. **Grade and mix.** Normalize the confirmed profile, balance shots, then one Edison finish (obsidian/graphite, crimson edge, warm skin). Build anticipation → impact → recovery in sound; remove platform outro audio.
5. **Proof and repair** difficult effects before the full render; then decode and inspect the export.

## Caption
Hook → development → one useful training insight → one CTA (save / follow / comment prompt). Ground it in the actual film; pillar EDISON TRAINS or THE STANDARD. Five hashtags.

## Honesty
A node that fails to render is not an effect. Frame blending is not optical flow. A shifted duplicate is not an independent clone. A numbered crop is not a second camera.
